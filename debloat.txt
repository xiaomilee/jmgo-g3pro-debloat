# JMGO G3 Pro projector (JmGO_G3pro, Android 4.4.2 / SDK 19, Softwinner 板)
# 方案：标准精简 —— 只禁广告/追踪/预装推送类组件
#
# 实际生效命令（2026-10-25 实测执行）：adb shell pm block <包名>
# 注意：本机内存小，pm disable-user 会被系统 OOM 杀死 (RC=137)，必须用 pm block。
#       pm block 是 Android 4.4 时代的标准命令，效果等同 disable：禁止运行、
#       从桌面隐藏，可随时 pm unblock 恢复，无需 Root。
#
# 恢复命令：adb shell pm unblock <包名>
# 例：adb shell pm unblock com.jmgo.preinstallmanager
#
# 已确认保留（勿动）：com.softwinner.update(OTA)、com.softwinner.tvremoteserver(遥控服务)、
#   com.jmgo.systemapi、com.jianguo.server、com.shafa.market(沙发管家，用户自装)、
#   com.wukongtv.wkhelper.remoteplugin2(悟空遥控，用户自装)
# 应用清单备份见 backup/ 目录
#
